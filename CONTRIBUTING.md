# Contributing

## Development setup

1. Create a Python 3.10-3.12 virtual environment.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Run `python -m compileall -q .`.
4. Run `python scripts/smoke_test.py`.
5. Run `pytest`.
6. Run the application with `streamlit run app.py`.

## Change expectations

- Keep imports consistent with the repository's root-level module layout.
- Avoid committing secrets, local environment files, caches, generated bytecode, or temporary artifacts.
- Keep model and preprocessing metadata synchronized with generated artifacts.
- Add or update tests when changing feature engineering or reusable business logic.
- Document behavior changes in the README or technical report when appropriate.
- Treat serialized model artifacts as trusted files only.

## Pull requests

A useful pull request should describe:

- what changed
- why it changed
- how it was tested
- any model or data implications
- any known limitations

The CI workflow performs dependency installation, Python compilation, smoke testing, and application import validation.
